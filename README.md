## 요구사항 분석

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 Error를 발생시키고 해당 메시지를 출력한 다음 해당 지점부터 다시 입력을 받는다.

#### 입출력 요구사항

- 입력
  - 로또 구입 금액 (1,000원 단위로 입력 받아야 함)
  - 당첨 번호 (6개의 숫자, 쉼표(,)를 기준으로 구분함)
  - 보너스 번호 (1개 숫자)
- 출력
  - 발행한 로또 수량
  - 수량만큼의 로또 번호 (오름차순)
  - 당첨 내역
  - 수익률 (소수점 둘째 자리에서 반올림)
  - 에러 상황 시 에러 문구 출력 ("[ERROR]"로 시작해야 함)

### 3. 프로그래밍 요구사항

#### 요구사항 1)

- Node.js 22.19.0 버전에서 실행 가능해야 한다.
- 프로그램 실행의 시작점은 App.js의 run()이다.
- package.json 파일은 변경할 수 없으며, 제공된 라이브러리와 스타일 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- 프로그램 종료 시 process.exit()를 호출하지 않는다.
- 프로그래밍 요구 사항에서 달리 명시하지 않는 한 파일, 패키지 등의 이름을 바꾸거나 이동하지 않는다.
- 자바스크립트 코드 컨벤션을 지키면서 프로그래밍한다.
  - 기본적으로 [JavaScript Style Guide](https://github.com/tipjs/javascript-style-guide)를 원칙으로 한다.

#### 요구사항 2)

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
  - 예를 들어 while문 안에 if문이 있으면 들여쓰기는 2이다.
  - 힌트: indent(인덴트, 들여쓰기) depth를 줄이는 좋은 방법은 함수(또는 메서드)를 분리하면 된다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.
- Jest를 이용하여 정리한 기능 목록이 정상적으로 작동하는지 테스트 코드로 확인한다.
  - 테스트 도구 사용법이 익숙하지 않다면 아래 문서를 참고하여 학습한 후 테스트를 구현한다
    - [Using Matchers](https://jestjs.io/docs/using-matchers)
    - [Testing Asynchronous Code](https://jestjs.io/docs/asynchronous)
    - [Jest로 파라미터화 테스트하기: test.each(), describe.each()](https://www.daleseo.com/jest-each/)

#### 요구사항 3)

- 함수(또는 메서드)의 길이가 15라인을 넘어가지 않도록 구현한다.
  - 함수(또는 메서드)가 한 가지 일만 잘 하도록 구현한다.
- else를 지양한다.
  - 때로는 if/else, when문을 사용하는 것이 더 깔끔해 보일 수 있다. 어느 경우에 쓰는 것이 적절할지 스스로 고민해 본다.
  - 힌트: if 조건절에서 값을 return하는 방식으로 구현하면 else를 사용하지 않아도 된다.
- 구현한 기능에 대한 단위 테스트를 작성한다. 단, UI(System.out, System.in, Scanner) 로직은 제외한다.

- `Random.pickUniqueNumbersInRange(1, 45, 6)`
- 새로운 Lotto 객체 생성
- 정렬된 로또를 로또 리스트에 추가
- 구매 개수만큼 반복
- 반환 : 로또 리스트

### 5) 한장의 로또에서 당첨 번호와 같은 숫자 체크

- 함수 명 : matchingNumber
- 매개변수 : 로또, 당첨 번호
- 변수 : count = 0

- 당첨 번호 리스트를 쉼표(,)를 기준으로 분리
  - split 메서드 사용
- 로또에 당첨 번호와 같은 숫자가 있으면 count + 1
- 반환 : count
  - 당첨 번호와 같은 숫자가 몇개 있는지

### 6) 한장의 로또에서 보너스볼과 같은 숫자가 있는지 체크

- 함수 명 : checkBonusNumber
- 매개변수 : 로또, 보너스 볼
- include 메서드 사용
- 반환 : boolean
  - true : 보너스 볼과 일치하는 숫자 있음
  - false : 보너스 볼과 일치하는 숫자 없음

### 7) 3~6개까지 일치하는 로또 개수 체크

- 함수 명 : MatchingNumberCount
- 매개변수 : 숫자(기준이 되는 일치 개수), 로또, 당첨번호, 보너스볼
- 변수 : count = 0
- 당첨 번호와 일치하는 개수 계산 (matchingNumber)
- 조건문
  - 매개변수의 숫자가 5이고 보너스볼이 존재하는 경우
    - 보너스볼과 일치하는 번호가 있는지 체크 (checkBonusNumber)
    - 5개 일치, 보너스볼 일치하는 경우 count + 1
  - 매개변수의 숫자가 3,4,6 일 경우
    - 해당 숫자와 같은 개수만큼 일치하는 경우 count + 1
- 반환 : count
  - 기준이 되는 숫자만큼 당첨번호와 일치하는 로또 개수

### 9) 당첨 내역

- 등수별 개수 집계
  - MatchingNumberCount 사용
  - 5와 5+보너스볼 분리하여 개수 카운트
- 총 당첨금 계산
  - ex) "5,000원" -> 5000
    - Number 메서드 사용
    - replace(/,/g, "").replace(/원/g, "")
  - total += 당첨 금액 + 당첨된 로또 개수
- 등수별 결과 출력

### 10) 수익률

- 당첨 금액의 합 / 구입 금액 \* 100 (둘째 자리에서 반올림)

## 실수를 통해 얻은 지식

### 1) 중복되는 숫자 검사

- 처음 했던 방식

```jsx
const isDuplicate = (numbers) => {
  if (numbers.some((number) => numbers.includes(number))) return true;
  return false;
};
```

- 문제점
  - 자기 자신도 포함하여 비교하기 때문에 무조건 true 발생
- 해결방안 : Set 객체 사용
  - Set() : 중복되지 않는 값들의 집합을 나타내는 객체
  ```jsx
  const isDuplicate = (numbers) => {
    const numberSet = new Set(numbers);
    if (numberSet.size !== numbers.length) return true;
    return false;
  };
  ```
